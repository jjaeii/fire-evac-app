# 제조공장 화재 대피 안내

작업자와 안전관리자가 화재 상황에서 **현재 작업구역 기준으로 대피 방향과 대피 확인 상태를 판단**하는 데 쓰는 모바일 웹앱입니다.

> 이 앱은 판단 보조 도구입니다. 최종 대피 판단과 현장 통제는 안전관리자가 합니다.
> 화재를 감지하거나, GPS로 위치를 추적하거나, 소방설비·119를 자동으로 작동시키지 않습니다.

## 기능

**작업자 화면**
- 이름 + 생년월일로 회원가입 → 자동 로그인
- 작업구역 QR 스캔(실시간 카메라 / 카메라 촬영 / 코드 직접 입력)으로 현재 위치 등록
- 화재 발생 시 전체 화면 경보 — 빨간 화면 + 사이렌 + 진동, 대피 방향·사용 가능 비상구 표시
- 관리자 알림 수신 및 확인

**관리자 화면**
- 화재 단계 입력(정상 / 이상징후 / 초기화재 / 확대화재 / 대형화재) + 발생 구역 지정
- **1층 도면 현황판** — 구역별 인원 이름, 화재 발생 구역 표시, 대피 확인 상태
- 작업자에게 알림 발송(전체 / 구역별) + 읽음 현황
- 사용 불가 대피로 지정 → 작업자 안내에서 자동 제외, 도면에 차단 표시
- 진압 완료 · 정상 복구
- 구역 QR 코드 등록, trace_id 포함 로그

## 실행

Node.js·Python 없이 PowerShell만으로 도는 로컬 서버가 들어 있습니다.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .claude/https-server.ps1
```

| 접속 위치 | 주소 | 카메라 |
|---|---|---|
| PC | `http://localhost:8123` | O (localhost는 보안 컨텍스트) |
| 휴대폰 (같은 Wi-Fi) | `https://<PC의 LAN IP>:8443` | O |
| 휴대폰에서 http로 접속 | 위 https 주소로 자동 이동 | O |

휴대폰 첫 접속 때 자체 서명 인증서 경고가 뜹니다. **고급 → 계속**을 누르면 들어갑니다.

**카메라는 `https` 또는 `localhost`에서만 열립니다.** `index.html`을 파일로 직접 열면(`file://`) 브라우저가 카메라를 차단합니다.

## 배포

정적 파일만으로 동작하므로 어떤 정적 호스팅에도 그대로 올라갑니다(빌드 불필요).

```
index.html
src/**
```

HTTPS로 서비스되는 곳에 올리면 방화벽·인증서 경고 없이 휴대폰에서 카메라가 바로 동작합니다.

단, 기기 간 상태 공유는 로컬 서버의 `/api/state`에 의존합니다. 정적 호스팅에서는 이 API가 없으므로 앱이 자동으로 **기기 저장 모드**로 전환됩니다(헤더 칩에 `기기 저장` 표시). 여러 기기가 같은 현장 상태를 봐야 한다면 서버가 필요합니다.

단일 파일 버전이 필요하면:

```bash
bash .claude/build-standalone.sh   # dist/fire-evac-standalone.html
```

## 구조

계층을 섞지 않는 것이 이 코드베이스의 규칙입니다.

| 계층 | 위치 | 역할 |
|---|---|---|
| L0 화면 | `src/components/` | 표시와 입력 전달만. 판단하지 않는다 |
| L1 기능 | `src/services/` | 판단·검증·기록. 정보가 부족하면 추측하지 않고 보류 반환 |
| L2 자료 | `src/repositories/`, `src/adapters/`, `src/data/` | 저장소 접근. localStorage는 어댑터에서만 만진다 |
| L3 기반 | `src/foundation/`, `src/constants/` | 로그·에러·상수·경보음. 문구와 상수는 여기서만 정의 |

- 모든 로그에는 `traceId`가 들어갑니다 (`TraceIdFactory` → `Logger`)
- 화면 문구와 화재 단계 문자열은 `src/constants/`에서만 정의합니다 (하드코딩 금지)
- 사람이 입력한 값은 `HtmlEscape`를 통과시킨 뒤에만 화면에 넣습니다
- 외부 서버·로그인·결제·GPS·AI 감지를 쓰지 않습니다
